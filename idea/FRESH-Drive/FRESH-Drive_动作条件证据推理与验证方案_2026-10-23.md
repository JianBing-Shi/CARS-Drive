# FRESH-Drive：刷新前的动作条件证据推理与验证方案

日期：2026-10-23（Asia/Shanghai）

本文是现有 FRESH-Drive 主线的补充研究设计，不替代已有的数据与训练方案。以下贡献均为待验证假设，不能据此宣称已具备 CVPR 录用水平或首次性。

## 1. 研究定位

将思维链融入 FRESH-Drive 时，重点应是可监督、实际参与决策的证据推理过程，而不是生成看起来合理的驾驶解释。

论文主张建议围绕：

> 刷新前的动作条件证据推理：模型根据已有视觉缓存与候选动作，判断证据缺口，并预测刷新各路相机能够带来的决策收益。

不建议将“首次把思维链用于驾驶”作为主要贡献表述。

## 2. 最小三步版本

优先实现：

```text
候选动作 → 证据缺口 → 刷新收益
```

可扩展为：

```text
候选动作
→ 相关冲突区域
→ 当前缓存中的视觉证据
→ 证据陈旧程度与不确定性
→ 各相机刷新收益
→ 获取所选新视觉后更新轨迹
```

所有刷新前的推理只能使用因果可用的旧视觉、自车运动、时间信息与导航提示。不得读取尚未刷新的当前图像，也不能在推理阶段通过真值参与者状态补回缺失证据。

优先使用结构化证据推理，避免每个规划周期调用大型语言模型。若中间输出只是并行辅助头，应如实称为结构化证据预测；不能仅凭多个输出就声称存在顺序推理。

## 3. 如何验证其对 CVPR 论文的价值

不能仅展示几段合理解释，需要以下三类实验。

### 3.1 同等预算对照

比较：

- 不含证据推理、直接预测刷新收益的 FRESH-Drive。
- 相同参数量的模型。
- 带普通辅助任务、但不通过中间证据变量决定刷新的模型。
- 使用结构化证据链决定刷新的模型。

计入证据推理模块的实际计算与延迟开销，在相同计算预算下比较刷新收益、决策后悔、规划质量与风险代理。不能只通过增大模型或增加计算量获得优势。

### 3.2 证据干预

遮挡相关视觉区域，或改变对应相机的时间年龄，检查：

- 证据缺口预测是否合理变化。
- 相机刷新选择是否相应变化。
- 新视觉是否实际改善动作选择。

加入同面积随机区域遮挡和非关键区域干预作为对照，避免模型仅对任意图像变化敏感。训练与评测明确区分图像干预和物理环境变化。

### 3.3 中间变量干预

替换或扰动证据缺口预测，检查后续刷新行为是否按预期变化，以验证中间变量确实参与决策。

可比较预测缺口、训练监督得到的参考缺口、随机缺口及打乱样本间缺口的结果。参考缺口仅用于诊断上限，不能混入正常推理结果。

中间变量影响输出只是必要证据之一，还需验证其语义准确性及最终决策收益，不能单凭干预有效就宣称因果解释已经成立。

## 4. 错误传播与不可观测性

必须分析冲突区域判断错误是否让调度器持续忽略某路相机，报告漏刷新、陈旧错误累积、恢复时间及保守回退频率。

旧视觉中完全没有线索的新事件不能凭空预测。最低周期刷新等机制需要纳入公平预算，不能用语言解释掩盖不可观测性，也不能据此宣称安全保证。

## 5. 实施顺序与继续条件

1. 先完成不含思维链的 FRESH-Drive 基线。
2. 加入“动作 → 证据缺口 → 刷新收益”的最小三步版本。
3. 完成同等预算对照、证据干预和中间变量干预。
4. 检查错误传播与突发事件表现。

如果该模块在相同计算预算下，跨独立录制与随机种子稳定改善刷新和规划，并通过上述干预验证，可以考虑作为方法贡献。

如果它只提高解释可读性，或收益可由普通辅助任务、模型容量与额外计算解释，应将其作为分析工具，不强行加入主方法。
