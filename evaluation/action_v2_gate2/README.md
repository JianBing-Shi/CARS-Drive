# Action v2 gate2 权重评估

日期：2026-11-06（Asia/Shanghai）。已完成全量验证集评估。

权重：`lightning_logs/action_v2_gate2/version_1/checkpoints/best.ckpt`，epoch 19 / global_step 3540。`best.ckpt` 与 `last.ckpt` 的全部模型参数相同。checkpoint 中的 ModelCheckpoint 监控 `val/ade`，记录的最佳分数为 0.125054 m。

模型为 action 模式、architecture_version 2、refresh_version 2，使用 20 帧历史与十步动作回放。此次只评价动作预测器；refresh_version 标记不代表执行了刷新门控。四项训练损失权重为 XY 0.50、dyaw 0.10、累计位置 0.35、累计航向 0.05，teacher forcing 为 0。

## 结果

mini 验证 manifest 共 1,246 个窗口，按 `(recording, anchor_timestamp_us)` 去重为 1,147 个锚点，覆盖 5 个 recording，保留 14 类事件标签。每项指标都有完整的 1,147 个有效样本。单位为米，越低越好。

| 模型 / 对照 | 十步 ADE | 十步 FDE | 固定五步 ADE | 固定五步 FDE |
|---|---:|---:|---:|---:|
| 本次 best.ckpt | 0.126892 | 0.230437 | 0.088403 | 0.151935 |
| 旧 action epoch 17 | 0.166747 | 0.321185 | 0.101251 | 0.209024 |
| 历史末步恒定动作 | 0.097313 | 0.230978 | 0.035499 | 0.069865 |

相对旧 epoch 17，本次十步 ADE/FDE 分别下降 **23.9% / 28.3%**，固定五步 ADE/FDE 分别下降 **12.7% / 27.3%**。旧结果来自 `evaluation/action_checkpoints/metrics.json`，使用相同的 1,147 个锚点、评估代码协议与 CPU 环境；已核对两份 CSV 的锚点集合完全相同，恒定动作基线指标一致。此次训练同时改变了架构和损失配方，不能把改善归因于其中某一项。

当前模型的十步 ADE 仍比恒定动作基线高约 30.4%；十步 FDE 仅略低，描述性结果不足以认定有优势。固定五步 ADE/FDE 分别约为基线的 **2.49 / 2.17 倍**，因此固定视觉候选还没有超过运动学对照。可以确认新训练改善了旧模型，但不能据此认为已经通过刷新阶段的候选质量验收。

锚点首步位置误差为 0.028420 m。固定视觉递推的第一至五步位置误差分别为 0.028420、0.054443、0.086669、0.120546、0.151935 m；持续观察回放在 0.5 s 时为 0.113468 m。这表明固定视觉候选的递推误差仍需单独关注。仅凭本次指标不能确定误差来自视觉利用、动作递推还是训练目标，需要后续消融区分。

`action_loss` 在本权重中为 `0.50 * L_xy + 0.10 * L_dyaw`，十步值为 0.006964；它不包含累计位置和航向项，且与旧权重的 `XY=1, yaw=1` 数值不可直接比较。ADE/FDE 不受损失权重改变影响。

## 协议与复现

```bash
conda run --no-capture-output -n FRESH-Drive python tools/evaluate_action_checkpoints.py \
  --config config/val/action_v2_gate2_checkpoints.yaml
```

- 十步回放：10 Hz，每步接收当时已到达的日志 BEV，使用自身动作前缀，评价 1.0 s。
- 固定五步：只使用锚点及历史视觉记忆，zero prefix、重置 decoder hidden，连续调用同一个单步头五次，评价 0.5 s。
- 恒定动作：重复锚点前最后一个局部 SE(2) 动作，不读取未来状态。
- 所有未来真值只用于离线评分。此次为日志回放，不是闭环驾驶评估；没有运行碰撞或闭环安全评价。
- FDE 要求配置时域完整有效；本次全部锚点均满足。事件分组保留多标签，同一锚点可属于多个事件组。
- CPU / PyTorch 1.13.1+cu117，正式推理与汇总耗时约 165.8 s，不包含数据转存；该耗时不作为在线延迟指标。本机 GPU 不可用，部署 GPU 上的绝对指标仍应复核。

`metrics.json` 保存配置、checkpoint 状态指纹、分事件结果和窗口加权结果；`per_sample.csv` 共 5,735 行，即五种评价场景各 1,147 行；`comparison.csv` 保存主要模型指标。未对相邻锚点进行独立样本显著性推断。

训练日志中的 ADE/FDE 为 0.125054/0.229222 m，固定五步为 0.086277/0.155992 m。本表使用 CPU 去重锚点均值；即使恢复 manifest 重复窗口加权，本次十步 ADE/FDE 仍为 0.127011/0.230682 m，与训练日志存在小幅差异，不能仅用去重解释。报告保留两者原值，最终表内比较使用统一重评估协议。
