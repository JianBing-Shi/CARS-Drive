## 2. 数据与推理协议

当前预处理数据采用 10 Hz 采样，每个窗口包含：

| 部分 | 时间范围 | 帧数 |
|---|---|---:|
| 历史观察 | 锚点前 2 秒 | 20 |
| 锚点观察 | 当前时刻 | 1 |
| 后续观察 | 锚点后 1 秒 | 10 |
| 总计 | 完整窗口 | 31 |

模型预测 10 个连续动作，每个动作为：

```text
[dx, dy, dyaw]
```

其中，位移在前一步自车坐标系下表达，航向变化采用弧度。

当前 action 模型采用时序回放：

- 前 20 帧用于建立历史视觉状态。
- 第 k 步读取第 `20+k` 帧，预测到下一时刻的动作，k 为 0～9。
- 最后一帧是最后一个动作的监督终点，不作为视觉输入。
- 训练使用前一步专家动作；验证使用前一步预测动作。
- 验证时不向模型输入未来专家动作。

因此，当前结果属于**专家日志上的因果观察回放与自回归动作预测**。后续观察仍来自记录中的专家驾驶过程，预测动作不会改变这些观察。

论文不能将其描述为闭环驾驶结果，也不能描述为仅在锚点观察一次、直接预测未来 1 秒的固定上下文规划结果。

## 4. ADE 与 FDE 的定义

预测动作首先通过 SE(2) 积分得到轨迹，然后与同一坐标系、同一时间点的专家轨迹比较。

设预测位置为 \(\hat p_t\)，专家位置为 \(p_t\)，完整预测包含 \(T=10\) 个位置点。

### 4.1 ADE：平均位移误差

\[
\mathrm{ADE}=\frac{1}{T}\sum_{t=1}^{T}\|\hat p_t-p_t\|_2
\]

ADE 表示整段轨迹平均偏离专家轨迹多少米，越低越好。

### 4.2 FDE：最终位移误差

\[
\mathrm{FDE}=\|\hat p_T-p_T\|_2
\]

FDE 表示预测终点偏离专家轨迹多少米，越低越好。

当前完整窗口的终点为 1 秒，因此：

```text
FDE@1s = L2@1s
```

ADE、FDE 只计算平面位置误差，不包含航向误差。航向误差由独立指标统计。

当前数据仅支持到 1 秒的评估，不应报告 L2@2s 或 L2@3s。

## 5. Plan-R1 指标的适配方式

Plan-R1 指标接收的单场景数据形状为：

```text
预测轨迹：[agent数, mode数, 时间步数, 2]
专家轨迹：[agent数, 时间步数, 2]
有效掩码：[agent数, 时间步数]
```

当前任务只有自车和一条预测轨迹，因此设置：

```text
agent数 = 1
mode数 = 1
```

在这个条件下，minJointADE、minJointFDE 分别退化为普通 ADE、FDE。

原始 Plan-R1 指标存在两个需要注意的行为：

1. 最后一个时间点无效时，整条场景可能被跳过。
2. 跳过后仍将场景计入分母，可能低估误差。

目前没有修改这两个指标文件，而是在 `val.py` 中适配：

- ADE 仅向指标传入连续有效前缀。
- FDE 仅在完整预测终点有效时计算。
- 全无效样本不调用指标，记录为缺失值。
- 每个样本计算前重置指标状态。
- 汇总时排除缺失值，并记录各指标实际参与统计的样本数。

这样可以保留原有评估含义，避免无效样本被当作零误差。

## 6. 当前输出内容

`val.py` 输出模型与恒定动作基线的以下指标：

| 指标 | 含义 |
|---|---|
| ADE | 整段积分轨迹的平均位置误差 |
| FDE | 完整预测终点的位置误差 |
| L2@0.1～1.0s | 每个时间点的位置误差 |
| Action dx/dy MAE | 局部动作位移的平均绝对误差 |
| Action dyaw MAE | 周期归一化后的动作航向误差 |
| Heading MAE | 积分轨迹的航向误差 |
| Action loss / loss | 与当前训练损失定义对应的误差 |

恒定动作基线重复使用锚点前最后一个局部 SE(2) 动作，不读取未来动作标签。它用于判断模型相对简单运动外推是否具有收益。

结果文件包括：

```text
metrics.json       总体指标、事件分组指标、有效样本数及运行配置
per_sample.csv     逐样本指标及样本标识
predictions.pt     可选的预测动作、积分轨迹、专家轨迹和掩码
```

脚本还记录缓存 BEV 模型前向耗时。该耗时不包含图像编码、数据加载和传输，不能作为完整系统端到端延迟。

## 8. 后续如何验证刷新机制

完成 action 模型评估后，应冻结同一个预测器，在相同状态、相同目标时间上比较三个分支：

| 分支 | 操作 | 用途 |
|---|---|---|
| 保留原规划 | 继续使用已有轨迹 | 判断是否确实需要改变规划 |
| 旧视觉重规划 | 使用旧缓存重新生成轨迹 | 分离重运行规划器本身的收益 |
| 新视觉重规划 | 更新指定视觉区域后生成轨迹 | 衡量新证据的额外作用 |

设三个分支的轨迹误差分别为 \(D_{\mathrm{keep}}\)、\(D_{\mathrm{old}}\)、\(D_{\mathrm{fresh}}\)，定义：

\[
U=D_{\mathrm{old}}-D_{\mathrm{fresh}}
\]

\[
W=D_{\mathrm{keep}}-D_{\mathrm{fresh}}
\]

其中：

- \(U>0\)：新视觉相对旧视觉重规划提供了额外收益。
- \(W>0\)：更新后的轨迹优于保留原规划。
- 只有两者均超过预先设定的阈值，才支持“新视觉帮助模型有益地修改原规划”。

后续论文需要展示：

1. 刷新前后的 ADE/FDE，以及 \(U\)、\(W\) 收益分布。
2. 需要刷新场景的召回率、错误触发率和有害采用率。
3. 固定视觉预算下，与随机区域、年龄优先等方法的比较。
4. 视觉事件出现、模型触发、轨迹改变和误差改善的案例。
5. 实际视觉更新成本与规划质量之间的关系。

“获取新视觉前选择哪里更新”和“新视觉到达后决定是否采用新规划”应分别评估，因为二者可用输入与计算成本不同。
